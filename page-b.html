建站资料整理标准

资料整理实操 · 约 3 分钟

一、先建立资料清单

每个文件至少登记：文件名、来源、日期、负责人、格式、用途、证据等级、保密级别。未经核验的表述标为「待核验」。

二、建议资料文件夹结构

建站资料/ ├─ 01-公司与品牌/ ├─ 02-产品与解决方案/ ├─ 03-目标客户与ICP/ └─ 99-待确认/ 建站资料-md/ ├─ 00-先看这个-资料逻辑.md └─ 01-首页MVP必填.md

三、整理规则

  • 原文件与结构化摘要分离，不覆盖原件。
  • 不能证明的内容写「未知/待确认」。
  • ICP、反 ICP 单独整理。
请先不要建站。根据建议资料文件夹结构，检查是否已有「建站资料」和「建站资料-md」。先输出拟创建目录，等待确认。

验收门

进入首页 MVP 前须明确：目标与转化、ICP/反 ICP、主推产品、证据资产、禁写规则、联系方式。

部署到 Vercel 与域名绑定

实操部分·约 10 分钟

本站为纯静态文件，适合 Vercel / Netlify / GitHub Pages。

方式 A：GitHub + Vercel（推荐）

  1. 在 vercel.com Import 本仓库
  2. Framework Preset 选 Other
  3. 直接 Deploy
  4. 在 Settings → Domains 绑定域名
npx vercel npx vercel --prod

验收门

生产环境 HTTPS 可访问；域名解析正确。
